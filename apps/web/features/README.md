# features/

Feature components are colocated here by domain, mirroring the API modules.

- `features/projects/` — project list, create/update forms
- `features/planner/` — milestones, tasks, kanban/board
- `features/artifacts/` — artifact list, version history
- `features/knowledge/` — collections, documents, uploads
- `features/notifications/` — in-app notification list
- `features/search/` — global search box + results
- `features/activity/` — project activity feed
- `features/auth/` — sign-in/sign-up forms, session UI

These are placeholders. Implement as features are built.

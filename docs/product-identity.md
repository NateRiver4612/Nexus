# Product Identity

> **Your workspace for turning knowledge into meaningful work.**

> **The AI-powered workspace built around getting projects done.**

---

# What Is Nexus?

**Nexus is an AI-powered personal workspace built around projects.**

It brings together the knowledge, planning, conversations, files, artifacts, activity, and context required to move a project from an idea to completion.

Instead of separating work across note-taking apps, AI chatbots, cloud storage, document editors, spreadsheets, task managers, and calendars, Nexus connects those pieces around a common unit:

> **The Project.**

The workspace remembers what users have learned, what they have created, where they are in their journey, and what needs attention next.

AI acts as a **context-aware collaborator** that can analyze information, suggest actions, answer questions, and create useful deliverables—while the user remains in control of the actual work.

# The Problem

Modern knowledge work is fragmented.

A typical project might look like:

```
Google Drive
     +
Notion
     +
ChatGPT
     +
Google Calendar
     +
Excel
     +
PowerPoint
     +
Slack
     +
Random PDFs
     +
Browser bookmarks
```

The problem isn't that these tools are individually bad.

The problem is that **the context is fragmented across them**.

Users constantly have to answer:

- Where did I save that?
- What was I working on?
- What did I learn?
- What was the conclusion from that meeting?
- Which version is the latest?
- What should I do next?
- Why did I create this document?
- What information did I use to create it?

Nexus attempts to solve this fragmentation.

---

# What Makes Nexus Different?

## 1. Project-Centered, Not Document-Centered

Traditional tools often begin with:

> "What document do you want to create?"

Nexus begins with:

> **"What are you trying to accomplish?"**

A project can contain:

- Knowledge
- Files
- Conversations
- Planner
- Milestones
- Tasks
- Artifacts
- Calendar events
- Activity
- AI context

The document is an output of the work—not the center of the work.

---

# 2. The Project Has a Memory

Every project gradually builds its own memory.

```
Project Memory
│
├── Knowledge
├── Conversations
├── Documents
├── Artifacts
├── Decisions
├── Activity
├── Planner Progress
└── Project Context
```

AI can use this context when assisting the user.

The user shouldn't repeatedly have to explain:

> "I'm working on this project, here's what I've already researched, here's the report I created, and here's what I'm trying to accomplish."

Nexus already knows the context.

---

# 3. AI Is a Collaborator, Not the Product

AI is embedded into the workflow rather than isolated inside a chatbot.

AI can:

- Understand project context
- Analyze knowledge
- Summarize information
- Suggest next actions
- Identify gaps
- Generate deliverables
- Review existing work
- Answer project questions
- Surface relevant information

But:

> **AI assists. The user decides.**

This is especially important for planning.

AI can suggest:

> "You may want to verify the competitor pricing data."

But the user decides whether that becomes a task.

---

# 4. Work Has a Journey

One of Nexus's core experiences is **progressive project completion**.

Instead of returning to a project and seeing a giant collection of files and tasks, users should be able to understand:

> **Where am I in this project?**

For example:

```
Market Research

Discovery             ✓
Research              ✓
Analysis              ●
Final Report          ○
Presentation          ○
```

Inside the current stage:

```
Analysis

✓ Review interview notes

○ Verify competitor pricing

○ Complete SWOT analysis

○ Draft recommendations
```

This creates a sense of progression.

---

# 5. Resume Working

Returning to a project shouldn't feel like reopening an empty workspace.

Nexus remembers the user's **last meaningful checkpoint**.

Example:

```
Resume Working

Market Research

You were here:

Analysis

Last worked:
Reviewed 12 interview responses

Next:
Verify competitor pricing

Estimated:
15 minutes
```

The goal is to remove the mental cost of:

> "Where was I?"

and replace it with:

> **"Let's continue."**

---

# 6. Knowledge → Work

Nexus should continuously connect information to action.

For example:

```
Upload Research
      ↓
Knowledge indexed
      ↓
AI understands research
      ↓
Insights discovered
      ↓

      ↓
```

Knowledge isn't simply stored.

It becomes **usable context**.

---

```
AI

```

```
├── Planner

├── Knowledge
```

> **README + cockpit**

- Current status
- Current journey position
- Resume Working

- Prioritized planner information
- Recent artifacts
- Important knowledge
- Recent activity

---

- Progress
- Checkpoints

---

### Knowledge

Answers:

> **"What do I know?"**

- Uploaded files
- Research
- Notes

### Artifacts

# AI's Role in Nexus

AI operates at multiple levels.

## Project Level

AI understands the overall project.

It can:

- Summarize project status
- Identify missing information
- Highlight risks
- Suggest next actions
- Review project health

---

## Knowledge Level

AI understands the project's knowledge.

It can:

- Search
- Summarize
- Compare
- Extract insights
- Answer questions
- Connect information

---

## Artifact Level

AI helps create and transform work.

Examples:

```
Report
   ↓
Presentation

Research
   ↓
Executive Summary

CSV
   ↓
Analysis

Meeting Notes
   ↓
Actionable Summary
```

---

## Planner Level

AI does **not** control the user's schedule.

Instead, it can:

- Suggest tasks
- Identify blocked work
- Highlight stale tasks
- Suggest what may be worth doing next
- Identify project-health issues
- Suggest artifacts that could help complete a milestone

The user decides what actually happens.

---

# Human + AI Responsibility

This distinction should become one of the core principles of Nexus.

| User                | AI                          |
| ------------------- | --------------------------- |
| Defines goals       | Understands goals           |
| Approves plans      | Suggests plans              |
| Creates/edits tasks | Suggests tasks              |
| Makes decisions     | Provides analysis           |
| Approves artifacts  | Generates artifacts         |
| Controls schedule   | Provides scheduling context |
| Owns final output   | Accelerates creation        |

> **AI removes friction. It doesn't remove agency.**

# What Nexus Is Not

Nexus is **not**:

### A Notion replacement

It isn't primarily a blank canvas for storing pages.

### A task manager

Tasks are part of projects, but tasks aren't the product.

### An AI chatbot

Chat is a capability, not the destination.

### A calendar application

Scheduling remains useful, but isn't the core experience.

### A document generator

Artifacts are outputs of meaningful work, not the entire product.

### A generic automation platform

Automation should be contextual and useful rather than requiring users to construct complex workflows.

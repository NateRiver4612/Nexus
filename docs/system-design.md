# System Design Document

> Nexus is a project-centric AI workspace designed to help individuals and teams transform knowledge into high-level deliverables. Unlike tranditional note-taking apps, or AI chat interfaces, Nexus gather many of productivities apps core features in one place, that is around user projects(objectives,goals). Each project contains knowledge, artifacts, planning, activity side by side with an AI assitant that evolve together throughout the projects’s lifecycle.

## Functional Requirements

- User can create/delete/archive their projects
- When create a project, users will go throught an AI-kickoff process to get start with the generated **Deliverables**
- User can edit the deliverables during the steps such as tasks, deadline, documents, context during the kickoff
- User can add/delete their documents as AI will use it as knowledges inside the project
- User can manage AI knowledges, view/add/delete and search
- User can generate the **Artifacts** with AI base on their context and the uploaded documents
- User can manage and search for the the artifacts inside the project or outside the project
- User can edit an artifact by going in it detail page where has an AI context to suggest the actions, or they can manually edit through an editor
- User can manage their planner deliverables, view/create/edit/delete and search, re-order tasks, milestones
- User can ask AI to suggest the best action base on current state of their plan
- User can generate the suggestions and execute the actions from AI
- User will focus mainly on the tasks, search, edit, delete
- User can go to task session page, where allow them to takes notes, chat with AI, upload files
